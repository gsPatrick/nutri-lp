# Instruções para Anexos do E-mail (PDFs)

Coloque os arquivos PDF reais dentro desta pasta (`api/assets/pdfs/`).
Os arquivos devem ter exatamente os seguintes nomes:

1. **`gut_reset_protocolo.pdf`** -> Este é o PDF principal que TODOS os compradores irão receber.
2. **`bonus_exames.pdf`** -> Este é o PDF bônus (Como interpretar seus exames do jeito certo), que será enviado APENAS para quem comprar no dia 01/04/2026.

Se o sistema não encontrar um dos arquivos, o e-mail será enviado sem o respectivo anexo.
